# Victor
Victor is a vector calculator where you can define 2d vectors and do operations on them.

# Features

1. We don't use floats do we? -> Yeah, we use our own custom defined Number type that stores numbers in ratio, just easier to work with them.
2. Proper BODMAS implemented.
3. A proper parser, lexer and token system.
4. A fantastic REPL

# How to install?
1. You need go 1.27.2+
2. then hit ```go install github.com/gog-official/victor@latest
``` in your terminal.
3. Now run with Victor
